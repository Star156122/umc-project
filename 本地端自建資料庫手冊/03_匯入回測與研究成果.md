# 03　匯入現有成果

## 一、同步研究工作台成果

確認 XAMPP 的 MySQL 已啟動，在「程式」資料夾執行：

```powershell
uv run python sync_research_mysql.py
```

程式會讀取 `data/research.sqlite3` 最新一筆研究成果，寫入 MariaDB 的：

- `research_runs`
- `strategy_metrics`
- `regime_metrics`
- `daily_risk`
- `trade_records`

重複執行同一筆研究資料會更新同一個批次，不會一直產生相同副本。這個動作不會重新回測，也不會呼叫 Gemini。

當 `.env` 的 `DB_ENABLED=true` 時，本機策略研究工作台的 `/api/research` 會直接讀取 MariaDB 最新批次；設為 `false` 時才改讀 `data/research.sqlite3`。頁面上方會顯示目前資料來源。

## 二、匯入原本個別回測報告

若要將 `reports/2303` 的回測摘要及 HTML 報告放進原本資料表，可執行：

```powershell
uv run python import_existing_report.py reports/2303
```

它會寫入 `analysis_records`、`backtest_results` 和 `reports`。正式匯入前必須先有：

- `users` 裡的 `user_id=1`
- `stocks` 裡的股票 `2303`

現有匯入程式會跳過名稱含 `test` 的測試報告，也會避免同一份正式報告重複上傳。

## 三、資料更新順序

策略或報告有更新時，建議依序執行：

```powershell
uv run python research.py build
uv run python sync_research_mysql.py
```

第一行使用現有報告更新研究資料與獨立 HTML；第二行再把最新研究資料同步到 MariaDB。
