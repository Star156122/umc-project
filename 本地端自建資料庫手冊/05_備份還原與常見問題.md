# 05　備份、還原與常見問題

## 備份資料庫

1. 進入 phpMyAdmin。
2. 點左側 `ai_stock_system`。
3. 點上方「匯出」。
4. 選擇「快速」及格式 `SQL`。
5. 按「匯出」，保存下載的 SQL 檔。

備份檔可能包含使用者資料及研究成果，不要公開放到 GitHub。

## 還原資料庫

1. 建立空的 `ai_stock_system`。
2. 點「匯入」。
3. 選擇之前匯出的 SQL 檔。
4. 按「執行」。

## 常見錯誤

### `Connection refused` 或「目標電腦拒絕連線」

XAMPP 的 MySQL 尚未啟動，或連接埠不是 `3306`。先確認 MySQL 顯示綠色，再檢查 XAMPP 顯示的 Port。

### `Access denied for user`

帳號或密碼錯誤。檢查 `.env` 的 `DB_USER` 和 `DB_PASSWORD`。

### `Unknown database ai_stock_system`

資料庫尚未建立。回到 phpMyAdmin建立同名資料庫。

### `Table doesn't exist`

尚未匯入資料表SQL。執行 `sync_research_mysql.py` 可自動建立研究資料表；原本專題資料表需匯入 `ai_stock_system.sql`。

### phpMyAdmin 打得開，但 Python 連不上

phpMyAdmin 透過 Apache 顯示，不代表 Python 的設定一定正確。執行：

```powershell
uv run python sync_research_mysql.py --check
```

依錯誤訊息檢查主機、連接埠、帳號和密碼。

### 組員能不能直接連我的 `127.0.0.1`？

不能。每個人的 `127.0.0.1` 都代表自己的電腦。若要共同使用，需要將資料庫部署到學校伺服器或雲端，並使用專用帳號、密碼、防火牆及備份機制。
