# 02　讓專案連接本機資料庫

## 一、建立 `.env`

在「程式」資料夾，將 `.env.example` 複製一份並命名為 `.env`。加入：

```dotenv
DB_ENABLED=true
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=ai_stock_system
DB_USER=root
DB_PASSWORD=
DB_USER_ID=1
STOCK_NAME=聯電
```

XAMPP 預設的本機 root 可能是空白密碼，所以 `DB_PASSWORD=` 後面不填。如果自己設定過密碼，就填自己的密碼。

`.env` 可能同時有 Gemini、券商及資料庫密碼，不可上傳 GitHub、傳給組員或放進報告。每位組員應使用自己的 `.env`。

## 二、測試資料庫連線

先開啟 XAMPP 的 MySQL，再到「程式」資料夾執行：

```powershell
uv run python sync_research_mysql.py --check
```

如果成功，會顯示五張研究資料表目前的資料筆數。

## 三、常見設定

| 設定 | 意思 |
| --- | --- |
| `DB_ENABLED` | 是否允許程式連接及寫入資料庫 |
| `DB_HOST` | 資料庫主機，本機通常是 `127.0.0.1` |
| `DB_PORT` | MariaDB 連接埠，XAMPP 預設為 `3306` |
| `DB_NAME` | 使用的資料庫名稱 |
| `DB_USER` | 資料庫帳號 |
| `DB_PASSWORD` | 資料庫密碼 |
| `DB_USER_ID` | 舊版回測資料要歸屬的使用者編號 |

正式部署或多人共同使用時，不要使用 root，也不要使用空白密碼。應建立只允許操作 `ai_stock_system` 的專用帳號。
