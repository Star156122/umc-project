# 專案操作手冊

這個資料夾集中保存本專案的安裝、啟動及資料庫操作說明。

## 第一次使用

請先閱讀 [網站安裝啟動與疑難排解手冊](網站安裝啟動與疑難排解手冊.md)。內容包含：

- XAMPP 與整合版資料庫建立
- Node.js、前端與 API 套件安裝
- `.env` 連線設定
- 網站啟動、登入與關閉方式
- 常見錯誤與處理方法

## 資料庫進階操作

需要匯入既有研究成果、了解資料表、備份或還原時，再閱讀 [本地端自建資料庫手冊](本地端自建資料庫手冊/README.md)。

> 注意：整合網站使用的資料庫是 `umc_topic_integrated`。舊版研究手冊中的 `ai_stock_system` 是另一套研究資料庫，兩者不要混用。
