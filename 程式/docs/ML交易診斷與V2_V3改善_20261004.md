# ML 交易診斷與 V2／V3 改善結果

## 本次處理範圍

本次只改善 ML 回測，沒有修改六種技術指標策略，也沒有開始 Hybrid Strategy。沿用六檔股票、原本資料切分、交易成本與模型主要參數，避免整個重寫。

- 訓練：2023-01-01～2024-12-31
- 驗證：2025-01-01～2025-06-30
- 開發測試：2026-01-01～2026-06-30
- locked / forbidden：2025-07-01～2025-12-31，完全未讀取
- 股票：2303、2330、2412、2881、2882、2002

## V1 問題診斷

V1 實際上不是 BUY／HOLD／SELL 三分類。它只預測「三日後報酬是否大於 1%」，再以機率轉成訊號：

- `p >= 0.60`：BUY
- `0.45 < p < 0.60`：HOLD
- `p <= 0.45`：SELL

因此負報酬與小幅正報酬都被放進同一個 Label 0，模型沒有直接學習 HOLD 和 SELL 的差別。零交易主因是模型最高預測機率達不到固定的 0.60：Random Forest 有 2 檔、XGBoost 有 3 檔、GRU 有 4 檔沒有 BUY；GRU 的機率尤其集中在 0.5 附近，訊號幾乎都是 HOLD。

完整診斷：[V1 診斷報告](../exports/ml_trading_diagnosis_20261004/report.html)

## V2 唯一主要修改

V2 把 Label 改為考慮買賣手續費與交易稅後的三分類：

- 淨報酬 `<= -1%`：SELL
- 淨報酬介於 `-1%` 與 `+1%`：HOLD
- 淨報酬 `>= +1%`：BUY

模型直接輸出三種類別，不再使用 V1 的固定 0.60 買進門檻。Features 與模型主要參數維持不變，確保這一輪只檢查 Label 和訊號產生方式的影響。

## V2 結果

| 模型 | 有交易股票 | 總交易 | 平均報酬 | 中位報酬 | 獲利股票 | Test Macro F1 | Test Macro AUC |
|---|---:|---:|---:|---:|---:|---:|---:|
| Random Forest | 6/6 | 90 | 6.24% | 1.91% | 3/6 | 0.382 | 0.585 |
| XGBoost | 5/6 | 64 | -2.84% | -2.52% | 1/6 | 0.363 | 0.580 |
| GRU | 6/6 | 135 | 3.99% | -0.88% | 3/6 | 0.291 | 0.482 |

三分類大幅減少零交易，但並未解決泛化問題。Random Forest 目前相對最好，但仍只有三檔獲利；XGBoost 在 2412 仍是零交易；GRU 的跨股票報酬差異仍大。三個模型都沒有穩定超越 Buy & Hold，因此 V2 判定為「部分改善，尚未達可用候選」。

完整結果：[V2 HTML 報告](../exports/ml_trading_v2_20261004/report.html)

## V3 Features 實驗

V3 保留 V2 的 Label、模型參數與交易規則，只增加事先固定的 Features：短中期報酬、量能比率與 Z-score、價格 Z-score、K 棒振幅、實體、收盤位置、24 根波動與趨勢斜率。

| 模型 | 有交易股票 | 總交易 | 平均報酬 | 中位報酬 | 獲利股票 | Test Macro F1 | Test Macro AUC |
|---|---:|---:|---:|---:|---:|---:|---:|
| Random Forest | 6/6 | 107 | 1.48% | -1.45% | 2/6 | 0.413 | 0.589 |
| XGBoost | 6/6 | 70 | -2.03% | -1.02% | 3/6 | 0.382 | 0.554 |
| GRU | 6/6 | 82 | 3.35% | 1.38% | 5/6 | 0.315 | 0.543 |

V3 對 GRU 的跨股票一致性有幫助：獲利股票由 V2 的 3/6 增為 5/6，報酬標準差由 10.31 降為 4.55。不過 2412 只有 1 筆交易，屬於證據不足；GRU 仍沒有穩定超越 Buy & Hold。Random Forest 和 XGBoost 沒有改善，表示新增 Features 對不同模型的效果不一致。V3 因此仍是開發研究結果，不凍結為正式候選。

完整結果：[V3 HTML 報告](../exports/ml_trading_v3_20261004/report.html)

## 新增績效欄位

每檔股票的回測摘要現在包含：

- 交易次數與勝率
- 平均單筆損益
- Gross Profit、Gross Loss
- Profit Factor
- Sharpe Ratio
- Max Drawdown
- Buy & Hold Benchmark

沒有交易時 Profit Factor 與 Sharpe Ratio 保留為空值，不製造不存在的數字。

## 下一步

本輪已完成 Label、訊號方式與 Features 的兩輪主要改善，依研究規範不再用同一批資料反覆調整。下一步應先選擇 V3 GRU 作為待驗證方向，事先固定評估標準，再找未看過的新股票做一次 Clean Validation；若要研究信心門檻或連續確認，必須另立實驗且不能用 locked / forbidden 資料調整。
