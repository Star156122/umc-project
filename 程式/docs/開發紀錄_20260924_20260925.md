- 使用前一天以前20個交易日判斷市場階段；漲跌超過5%分為上漲／下跌，其餘為盤整，避免使用未來資料。

### 推薦規則

正式推薦必須同時符合：

1. 淨報酬大於0。
2. Profit Factor大於1。
3. Sharpe大於0。
4. 至少5筆完成交易。
5. 報酬超越同期買進持有。

未全部符合時，依情況顯示「候選觀察」或「暫不適用」。系統允許沒有推薦策略，不會每檔股票硬挑一個最高值。
