# 近期進度彙報講稿（2026/09/24～2026/10/05）

老師好，我們上次開會之後，主要完成三個方向：第一是把 ML 的訓練與驗證流程整理完整；第二是測試模型能不能泛化到沒有參與訓練的股票；第三是把技術策略回測、資料庫和網站串接起來。

首先是 ML 流程。我們現在把資料明確分成 Training、Controlled Validation、Development、Additional Holdout 和 Final Out-of-Sample。Training 使用 2023 到 2024 年，並在裡面做四折 expanding-window Walk-forward。也就是每一折都只用較早的資料訓練，再用後面的資料驗證，而且 scaler、class weight 和 GRU Early Stopping 都只能使用該折 Training，避免未來資料洩漏。

在這套流程下，目前 Training 內部暫時由 Random Forest 表現相對最好，平均 Macro F1 大約是 0.394，Macro AUC 大約是 0.580。不過這還只是 Training 內部結果，所以目前只稱為 Candidate，還沒有正式 Freeze，也沒有啟動 Controlled Validation。

接著，我們處理了原本 ML 回測中部分股票完全沒有交易的問題。V1 原本只預測三日後是否上漲超過 1%，再用固定機率門檻轉成 BUY、HOLD、SELL，因此模型的機率如果集中在 0.5 左右，就會一直輸出 HOLD。V2 改成考慮交易成本的 SELL、HOLD、BUY 三分類，V3 再增加市場結構、價格與量能 Features。這讓零交易問題明顯減少，但跨股票績效仍不夠穩定。

我們後來也做了 Feature Audit 和 Ablation。檢查後確認 `range_vs_close` 的公式和 Feature index 沒有錯，第 24 根 K 棒固定接近零，是因為取到 13:30 收盤撮合的一價 K 棒，不是程式計算錯誤。另外，Daily Features 原本會在 24 個 timestep 重複出現，現在已改成獨立的 static context：RF 和 XGBoost 只附加一次，GRU 則是在編碼完日內序列後才串接。

再來是這次最重要的泛化測試。我們把科技與金融各擴充到五檔股票，做 Leave-One-Stock-Out。每一次都留下一檔股票完全不參與訓練，只使用同產業另外四檔訓練，再預測留下來的股票。這樣測到的不是模型記住某一檔股票，而是能不能把同產業的規律套用到新股票。

目前結果顯示金融組比科技組相對穩定。科技組三個模型的 Macro AUC 約在 0.481 到 0.497；金融組的 GRU Macro AUC 約為 0.527，其中 BUY AUC 約為 0.560，金融 XGBoost 的 Macro AUC 約為 0.511。這代表金融股可能存在一些較一致的弱分類訊號，但科技股的跨股票泛化目前仍接近隨機。

我們也把 LOSO 的預測直接轉成 Training Backtest。相對比較好的金融 XGBoost，報酬約負 2.49%，共有 171 筆交易，勝率約 48.5%，Profit Factor 約 0.82，最差股票的最大回撤約 12.6%。科技組相對較好的 Random Forest 報酬仍約負 16.8%。

這表示目前模型在分類上有部分訊號，但直接轉成獨立交易策略後，還會受到錯誤 BUY、交易成本和持有規則影響。因此我們不把結果描述成模型失敗，而是把它定位成：分類能力尚有弱訊號，但獨立交易還不夠穩定。

因為參數比較與 Feature Ablation 都只有小幅或不一致的改善，所以目前不再一直針對 Training 調參。繼續搜尋很容易把同一段資料調得很好看，卻無法套用到新股票或新時間。下一步會先固定 Candidate 和判定標準，再進行一次有存取紀錄的 Controlled Validation。

網站方面，目前已經完成註冊登入、Yahoo 股票行情與搜尋、K 線圖、自選股、六種技術策略回測，以及 MySQL 報告保存。分析頁可以查看歷史報告、報酬、勝率、Profit Factor、最大回撤、技術訊號、交易紀錄、原始 HTML 報告與 Gemini 分析；另外也加入最新新聞和回測期間新聞。

目前網站展示的是技術策略回測；ML、LOSO 和 Hybrid Strategy 的結果尚未整合到網站。設定頁中的通知、修改密碼和分析偏好也還只有介面。

下一步我們預計先完成三件事。第一，根據 Training-only 和 LOSO 結果固定 ML Candidate，停止擴大調參。第二，Candidate Freeze 後執行一次 Controlled Validation，確認跨時間能力。第三，如果 Validation 顯示仍有可用訊號，就把 ML 作為技術策略的輔助確認，例如過濾低信心進場或調整訊號強度，再把 Hybrid 結果整合到前端和資料庫。

目前我們的結論是：ML 已完成可重現、可防止資料洩漏的研究流程，也完成跨股票產業測試；模型在金融股上看到部分弱訊號，但單獨交易仍不夠穩定。因此下一階段的重點不是繼續把 Training 數字調高，而是驗證跨時間能力，以及確認 ML 能不能提升既有技術策略的穩定性。
