# 研究路線與驗證規範

## 現階段目標

研究「固定的上漲行情篩選，能否讓區間突破在多檔股票上降低風險，且扣除合理交易成本後仍有獲利」。目前沒有通過獨立驗證的可用策略。

先集中一條趨勢主線：區間突破作主要研究候選，MA保留為比較基準。布林通道及原本的切換策略保留研究紀錄，不急著繼續調參。盤整、下跌不進場是下一個待驗證假設，尚未測出改善效果，不能說已實作或通過。

## 已有證據

- 六檔切換策略平均報酬約0.53%，只有聯發科、台灣大獲利。
- 台灣大的2.62%報酬只有1筆完整交易，不足以證明穩定。
- 六檔各10萬元，合計淨利約3,184.70元；聯發科淨利3,945.39元。拿掉聯發科後，其餘五檔平均報酬約-0.15%。此為集中度診斷，不是剔除股票來挑好看的結果。
- 長榮切換策略毛利約5,016元，成本約5,040元，淨損約24元；成本是必須檢查的問題。
- 平均回撤下降也可能只是持倉時間變短，不能直接歸功於行情分類準確。
- 上述均來自已用過資料的探索；六檔平均回撤不等於投資組合最大回撤。

## 下一次實驗順序

1. 先稽核既有切換結果：成交價、持倉時間、交易次數、獲利集中度，以及不利成交價格造成的影響。此階段不修改買賣參數。
2. 在開發資料只測一個預先登記的假設：上漲用固定v2區間突破；其他行情不新進場。必須先固定舊持倉平倉方式、暖機資料與成本假設。
3. 比較固定突破、上述篩選版本、MA、買進持有、全程現金。全部股票都要保留；記錄報酬中位數、獲利股票數、回撤、持倉比例、成本及逐筆交易。
4. 只有當開發結果值得保留，才鎖定程式與設定的SHA256，並事先登記未使用驗證期間、股票清單、成本與通過門檻，再執行獨立驗證。
5. 目前尚未指定或使用新的獨立驗證期間。可優先考慮凍結後的前向模擬，累積足夠行情與交易樣本再判斷，不用幾天結果下結論。

## 固定原則

- 看完結果不改日期、剔除虧損股票或降低通過門檻。
- 對驗證結果做修改後，該資料就升格為開發資料，後續需另找未使用資料。
- 每次記錄假設、版本、資料用途與失敗結果；不大量搜尋最佳參數。
- 兩次成交不等於兩筆完整交易；零交易與一筆獲利都不能當成穩定證據。
- 歷史整段績效不能拿來決定同段早期交易；行情分類必須只讀當時已知資料。
- 分段資產貢獻不是實際切換策略報酬；須以單一帳戶、真實成交順序及費用模擬。
- 正式建議維持暫不交易，直到獨立驗證有足夠證據。
