# ML 交易回測 V1

## 固定研究規格

- 股票：2303、2330、2412、2881、2882、2002。
- 訓練：2023-01-01～2024-12-31。
- 驗證：2025-01-01～2025-06-30。
- 保留區間：2025-07-01～2025-12-31，禁止讀取。
- 回測：2026-01-01～2026-06-30。
- 資料：5 分 K；每個交易日用最後 24 根已完成 K 棒建立訊號。
- 預測目標：下一個交易日開盤買進，持有到第三個交易日收盤的報酬是否超過 1%。
- 模型：Random Forest、XGBoost、GRU，使用同一份特徵、標籤與時間切分。

## 交易規則

- 機率大於等於 0.60：下一交易日開盤買進。
- 機率大於 0.45 且小於 0.60：維持原部位。
- 機率小於等於 0.45：下一交易日開盤賣出。
- 最多持有 3 個交易日，停損 3%，不設停利與移動停損。
- 初始資金 100,000 元，每次最多使用 95% 資金，最多 1,000 股；買不起整張時可買零股。
- 手續費買賣各 0.1425%，賣出交易稅 0.3%。
- 比較基準：買進持有與現金。

## 執行方式

在 `程式` 資料夾執行：

```powershell
uv run python .\scripts\run_ml_trading_v1.py
```

程式先檢查三段資料是否對六檔股票都齊全。資料不足時只產生缺口報告，不會訓練、不會回測，也不會拿其他期間替代。

## 輸出位置

- `exports/ml_trading_v1_20261003/data_coverage.csv`：每段期間、每檔股票的資料涵蓋。
- `exports/ml_trading_v1_20261003/results.json`：執行狀態或正式結果。
- `exports/ml_trading_v1_20261003/report.html`：本次完整報告。
- `exports/ml_trading_v1_latest.html`：方便前端或老師直接開啟的最新版報告。

## 2026 上半年首次固定規格結果

本次成功建立 2,868 筆訓練樣本、668 筆驗證樣本與 677 筆測試樣本。測試 ROC AUC 為 Random Forest 0.531、XGBoost 0.533、GRU 0.507，整體只略高於或接近隨機排序。

|XGBoost|0.00%|-21.38%|0.00%|0.00%|4.06%|-1.00%|

|買進持有|-0.31%|114.35%|51.37%|6.62%|32.13%|22.36%|

目前三個模型都沒有在六檔股票上穩定優於買進持有，而且部分股票因機率未達 0.60 而完全沒有交易。因此本版完成了「ML 可以產生交易並回測」的基礎流程，但尚不適合直接與技術策略融合。這組測試結果已看過，不應再依它調整門檻後宣稱是獨立驗證。
