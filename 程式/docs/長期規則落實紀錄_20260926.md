# 長期研究規則與日期鎖落實紀錄

本次只建立長期規範及防護，不讀取2025下半年行情，不重跑策略調參。

## 檔案位置

- 專案根目錄 `AGENTS.md`：未來修改專案時須先閱讀長期規範。
- `docs/長期研究規範.md`：六策略方向、跨股票測試、必要指標、避免過度擬合、Holdout首次使用與後續限制。
- `configs/holdout_policy.json`：2025/07/01～2025/12/31，access=forbidden。
- `trading_system/research_guard.py`：共用日期交集檢查、暖機範圍檢查、實際回放時間檢查、報告中繼資料檢查。
- `tests/test_research_guard.py`：合成日期及模擬連線的拒絕測試。

## 程式保護範圍

回測設定驗證、建立策略、下載與快取入口、逐日快取、K棒與Tick回放、報告產生、批次設定、實驗讀取、跨股票CSV比較、研究工作台資料重組、MariaDB研究結果讀取／同步、LLM分析入口均接入檢查。JSON報告先檢查日期中繼資料再允許分析，不把設定中的holdout保留宣告誤當成實際回測範圍。

一般入口沒有命令列或環境變數解鎖功能。設定檔被意外改成allowed也拒絕開發執行。缺少設定或日期格式有誤時停止，不默默放行。暖機跨入保留期也會拒絕。

這是專案程式層級的防誤用機制，不是作業系統存取權限：不能阻止人在專案外自行直接讀檔、執行SQL或修改原始碼。未來新增入口仍必須接入日期鎖。既有靜態HTML不會因Python程式更新而自動增加保護；本次沒有建立任何保留期HTML。

## 正式驗證

目前維持locked_unseen，尚未提供正式驗證執行器。使用者明確授權後，另建立凍結版本與候選、授權紀錄、首次存取即標記consumed、結果不可覆寫的專用流程。一般入口不解鎖。正式驗證若失敗仍保存，不拿結果回頭調參後重測同期間。

## 確認結果

完整單元測試通過；另測試實際Tick日期在沒有回測設定時也會被擋住。語法編譯檢查通過。測試使用合成資料與模擬連線，未下載或讀取Holdout行情。
