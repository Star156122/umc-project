## 啟動

1. 啟動專案設定使用的 MySQL。
2. 舊 API 視窗按 Ctrl+C，再開專案根目錄「啟動API.cmd」，避免同時啟動兩份占用 3000。
3. 開「啟動前端.cmd」。
4. 依終端機顯示的 Local 網址開網頁，Ctrl+F5 重新整理，登入後進策略模擬。
