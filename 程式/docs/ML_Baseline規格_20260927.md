# Machine Learning Baseline 固定規格

本輪只比較模型預測能力，不和交易策略混合，也不把模型預測轉成買賣績效。

## 預測問題

每一筆樣本使用同一交易日內，最近24根完成的5分K，預測第12根未來5分K收盤是否高於目前收盤。換句話說，用約2小時的歷史資料預測約60分鐘後的方向。

- 上漲：`close[t+12] > close[t]`
- 下跌或持平：其他情況
- 序列與Target不能跨日、不能跨缺漏K棒。
- 不使用未來特徵。

## 資料身分

使用14檔、2026/01/01～2026/06/30既有5分K。這些資料都已在策略研究中看過，所以只標記為 `ml_development_seen`，不是新的獨立測試。

時間切分固定為：

- Training：2026/01/01～2026/03/31
- Validation：2026/04/01～2026/05/15
- Test：2026/05/18～2026/06/30

資料不隨機打散。GRU early stopping 只能看 Validation，Test 不參與訓練、早停或改參數。

## 資料清理

- 休市日不是缺失值，不補資料。
- 重複時間戳保留第一筆並計數。
- 價格非正、成交量為負、High／Low 與 Open／Close 關係不合理的資料列排除並計數。
- 指標暖機造成的空值直接移除。
- 其他缺失值移除並計數。
- 交易日內缺K棒不補值；樣本序列不得跨越缺口。
- 真實跳空、漲跌停或大量成交不因幅度大而自動刪除。

## 特徵與標準化

使用價格相對變化、成交量比、MA相對位置、RSI、MACD、波動與趨勢斜率。價格使用比例特徵，避免模型只記住某檔股票的絕對股價。

Scaler 只可在 Training 上 `fit`，再套用到 Validation 與 Test。三個模型使用完全相同的標準化序列；RF／XGBoost 將24×15序列攤平成一列，GRU保留24×15形狀。

## 模型與評估

只跑一組事前固定參數：Random Forest、XGBoost、單層GRU。不得掃描大量組合。

共同指標：Accuracy、Precision、Recall、F1、ROC-AUC、Confusion Matrix、訓練時間與預測時間。另列每檔股票、平均值與中位數。所有失敗結果都保留。

本輪完成後只能說明「在這批已看過的開發資料切分中，三種模型的Baseline表現」，不能宣稱獨立泛化或未來獲利。
