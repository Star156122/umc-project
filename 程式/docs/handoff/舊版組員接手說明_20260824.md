# 組員接手說明

整理日期：2026-08-24  
本交付版已排除 `.env`、虛擬環境、套件快取、Python 快取與執行紀錄，避免洩漏 API Key 或夾帶可重建的大型檔案。

## 第一次使用

1. 將 `.env.example` 複製為 `.env`。
2. 只在自己的 `.env` 填入 Shioaji、TSST、MariaDB 或 OpenAI 金鑰；不要把 `.env` 傳回群組或提交版本控制。
3. 在專案資料夾執行 `uv sync` 安裝依賴。
4. 回測設定放在 `backtest_config.json`，執行方式請看 `README.md`。

## OpenAI LLM

- 預設關閉，不會自行呼叫 API 或產生費用。
- 啟用時在 `.env` 設定 `LLM_ENABLED=true`、`OPENAI_API_KEY=...`。
- 新回測會把結果寫入 `llm_report.json`、`summary.json`、`report.html`，資料庫開啟時也會保存於 `reports.report_content`。
- 現有正式報告可用 `uv run python enrich_existing_reports.py reports/2303` 補上分析，不需要重跑半年回測。
- 同一資料與模型會使用本地快取；除非確定要重新付費，否則不要加 `--force`。
