# 策略研究工作台怎麼使用？

這次直接新增程式功能，沒有修改或刪除舊的 reports 報告。

## 啟動方式

在「程式」資料夾開啟終端機，執行：

```powershell
uv run python research.py build
uv run python research.py serve
```

接著用瀏覽器開啟 http://127.0.0.1:8765 。終端機要保持開啟，按 Ctrl+C 可關閉網站。

第一次建立的資料已經保存在 `data/research.sqlite3`，只想看畫面可以直接執行第二行。

## 目前能做什麼？

- 顯示同一股票、期間、本金的六策略比較，依報酬率排序。
- 分別標示報酬率最高及最大回撤最小的策略，不把兩種排名混成「最好」。
- 選擇策略，查看上漲、盤整、下跌及資料不足期間的損益貢獻。
- 查看每日收盤資產、每日最大回撤，以及買賣成交紀錄。
- 六策略表格可點欄位排序；成交紀錄可搜尋、篩選買賣方向及下載 CSV。
- 市場階段損益增加長條圖，獲利和虧損用不同顏色呈現。
- 網頁透過 `/api/research` 讀取 SQLite 研究資料庫最新一筆研究結果，不是把資料直接寫死在 HTML 裡。
- 每次建立資料時，同時輸出 `exports/research_dashboard_latest.html`。這份檔案可直接雙擊開啟，不必啟動本機網站。

## 如何分類市場階段？

預設使用前一天收盤，相對於再往前 20 個交易日收盤的漲跌幅：超過 5% 為上漲、低於 -5% 為下跌，其餘為盤整。只使用當天以前的價格。這是研究用的初版規則，不是公認唯一的分類方法。

沒有足夠歷史收盤資料的前 21 個交易日列為「資料不足」。目前不另外下載回測開始前的行情。某類行情沒有出現時，顯示「無資料」，不硬切出一個階段。

每一天的損益是當天收盤資產減去前一天收盤資產，包含持股尚未賣出的市值變化、手續費與交易稅。跨日交易不會全部歸到賣出那天。將同類行情的每日損益加總，再除以原始本金，得到「全期報酬貢獻」，四類相加等於全期報酬。

每日最大回撤是當天各根 5 分 K 的資產，相對於回測開始以來資產最高點的最大跌幅。它不是單日跌幅，也不是該類行情重新起算的最大回撤。

可另建不同分類規則的研究結果，但不要看到結果後反覆挑最有利的門檻：

```powershell
uv run python research.py build --lookback 20 --threshold 0.05
```

## 固定參數

首次建立研究資料時，會把目前 `backtest_config.json` 保存到 `configs/frozen_baseline.json`，並建立 `.sha256` 檢查碼。之後建立研究資料會沿用這份保存版本，不會因為一般設定檔修改就跟著變動。

要用這份保存設定重新執行六策略，可執行：

```powershell
uv run python research.py run-fixed
```

這個指令先檢查保存檔是否被改動，再將保存檔交給原本的整批回測程式。它會產生新報告，並沿用原回測流程的行情、資料庫及 LLM 環境設定；不會自動停用原本啟用的服務。這次開發沒有執行這個重跑指令，也沒有呼叫 LLM。

注意：這是保存「設定檔版本」，尚未鎖定程式碼、套件、行情資料與所有環境設定。舊報告也沒有完整參數來源紀錄，不能宣稱舊報告已經用這份設定重新驗證。研究頁面會明確標示這件事。

## 程式放在哪裡？

| 檔案 | 用途 |
| --- | --- |
| `research.py` | 執行入口 |
| `scripts/research.py` | 建立資料、啟動網站及固定設定重跑的操作流程 |
| `trading_system/research.py` | 市場階段分類、每日資產與損益計算、研究資料存取 |
| `web/research.html` | 網頁畫面與表格 |
| `configs/frozen_baseline.json` | 本次保存的設定檔 |
| `data/research.sqlite3` | 新增的研究資料庫，每次建立保留一筆研究結果 |
| `exports/research_dashboard_latest.html` | 可直接開啟及交給組員查看的單一網頁 |
| `tests/test_research.py` | 分類、跨日損益、交易成本、參數保存及資料庫測試 |

## 還沒做的部分

目前是本機可使用的研究頁面，還沒接到組員的網站或 MySQL/MariaDB。現有資料庫匯入程式保持原樣。新的研究結果已拆成 `research_runs`、`strategy_metrics`、`regime_metrics`、`daily_risk`、`trade_records` 五張表；舊版 JSON 紀錄仍保留，程式可繼續讀取。

目前只分析現有聯電資料，未完成多檔股票或產業比較。來源是同期間每個策略最新產生的正式報告，不保證六份來自同一次整批執行。頁面會顯示來源路徑。研究分類不會影響任何原始買賣訊號。
