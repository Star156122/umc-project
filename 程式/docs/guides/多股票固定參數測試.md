# 多股票固定參數測試

## 第一輪股票

| 股票 | 產業 | 用途 |
| --- | --- | --- |
| 2303 聯電 | 半導體業 | 原始研究標的 |
| 2330 台積電 | 半導體業 | 同產業大型股 |
| 2881 富邦金 | 金融保險 | 跨產業大型股 |
| 2882 國泰金 | 金融保險 | 跨產業大型股 |
| 2412 中華電 | 通信網路業 | 首檔流程驗證、偏穩定股性 |
| 2002 中鋼 | 鋼鐵工業 | 景氣循環股 |

股票資料放在 `configs/stocks.json`，固定策略放在 `configs/strategy_templates.json`，本次實驗範圍放在 `configs/multi_stock_experiment.json`。增加股票時不用複製六份策略設定。

策略參數來源是聯電2026年上半年的固定版本。測試其他股票時不得依結果調整，否則無法檢驗泛化能力。

## 只檢查計畫

```powershell
uv run python multi_stock_batch.py
```

這是預設安全模式，只檢查設定並產生一份批次計畫，不會下載行情或回測。預設首檔為2412中華電。

## 實際執行首檔驗證

```powershell
uv run python multi_stock_batch.py --execute
```

執行前必須有可使用的行情來源金鑰，或資料庫已經有2412在指定期間的完整行情。LLM在批次階段保持關閉。

如果畫面顯示缺少 `API_KEY`、`API_SECRET`，代表本機只有聯電行情，程式必須登入永豐 Shioaji 才能取得其他股票資料。請直接編輯 `程式/.env`：

```dotenv
API_KEY=你的Shioaji_API_Key
API_SECRET=你的Shioaji_Secret_Key
```

金鑰需在永豐 API 管理頁申請並開啟「行情／資料」權限。Secret Key 只會顯示一次，請自行保存；不要把 `.env`、金鑰或含金鑰的截圖傳給組員，也不要上傳 GitHub。只下載行情與執行回測不需要憑證密碼，專案的 `ALLOW_REAL_TRADING=false` 仍須保持不變。

程式現在會先檢查本機行情與金鑰。條件不足時會在建立批次紀錄前停止，因此不會再多出一筆失敗報告或資料庫批次。

首檔完成且結果正確後，才執行完整六檔：

```powershell
uv run python multi_stock_batch.py --execute --all
```

也可只選指定股票：

```powershell
uv run python multi_stock_batch.py --execute --stock 2330 --stock 2881
```

## 檔案與資料庫控制

每次執行只建立一份 `data/batches/批次編號.json`，記錄固定參數版本、股票清單、狀態及錯誤。資料庫使用新增的 `experiment_batches` 和 `experiment_stocks` 保存批次進度。

目前底層回測仍會產生個別 `report.html`、CSV與總比較頁，因為研究明細及人工核對仍需要它們。尚未完成「寫入研究資料表後自動清除個別檔案」，所以第一輪先跑一檔，確認保留規則後再跑完整清單。原有2303報告不會被清除。

## 建立跨股票總覽

六檔股票完成後執行：

```powershell
uv run python cross_stock_dashboard.py
```

輸出位置是 `exports/cross_stock_dashboard_latest.html`。這個頁面包含六檔股票 × 六策略報酬率、超額報酬、成本占比、獲利股票數、市場階段及推薦判定。第一輪固定參數證據另存在 `data/baselines/cross_stock_fixed_v1.json`；程式不會覆蓋已有且來源不同的基準版。

啟動研究工作台後，也可以開啟：

```text
http://127.0.0.1:8765/cross-stock
```

## 候選 v2（不要覆蓋 v1）

候選版只檢查計畫：

```powershell
uv run python multi_stock_batch.py --template configs/strategy_templates_v2_candidate.json
```

候選版針對 RSI、MACD、區間突破與多數決增加持有／冷卻控制，目標是降低交易成本。它尚未經不同期間驗證，不可直接稱為改善成功，也不可刪除或覆蓋 v1 報告。

第二輪首檔流程驗證使用：

```powershell
uv run python multi_stock_batch.py --execute `
  --stocks-file configs/stock_universe_v2.json `
  --experiment configs/multi_stock_experiment_v2.json `
  --template configs/strategy_templates_v2_candidate.json
```

預設只跑3045台灣大及MA、布林通道、區間突破。確認結果後若要執行第二輪新增6檔，再加上 `--all`。第二輪日期是2026/07/01～09/24，與第一輪不同。
