# 成交量及資料來源

- 原匯入器：`scripts/import_technical_v1_training_kbars.py`，使用 Shioaji api.kbars 的 Volume 欄位，依 5 分鐘加總，沒有在匯入時乘 1,000。
- 官方 API 行情報價文件：https://sinotrade.github.io/zh/tutor/market_data/streaming/stocks/ ，普通整股成交量單位為張，與零股的股不同。
- 本次以證交所 2023–2024 STOCK_DAY 成交股數交叉查核本地每日量的量級：官方股數／本地量中位數約 1,195，支持本地單位為張，模擬統一乘 1,000。
- 不主張每日精確相等；本次交易時段固定 09:00–13:25，與官方全日量包含的撮合／其他交易範圍有差異，尤其最後收盤撮合。量級交叉查核不是逐筆資料認證。
- 證交所指數 FMTQIK 及個股 STOCK_DAY 各下載 24 個月份，只要求 2023–2024。原始官方回應及 URL／雜湊保存於本資料夾。
- legacy 回應部分中文欄名有編碼亂碼，日期與數值以固定官方欄位順序解析；數值已核對資料型別，欄名不作訊號輸入。
- 原始 SQLite 庫均以 mode=ro 與 query_only 讀取，查詢有起迄 timestamp 限制。不能只因檔案名稱有 training 就忽略日期鎖。
