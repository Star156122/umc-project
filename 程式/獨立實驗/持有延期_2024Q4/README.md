## 固定規則（研究起點，並非最佳設定）

- 原持有期限162根已觀測5分K不變；未到期不干預原出場。
- 到期時，預估以當根收盤加計賣出滑價、手續費、稅之後仍須浮盈。計入既有買入成本與已認列股利。
- 指標須有效，且收盤>MA20>MA60、收盤>MA240、趨勢斜率>0。不是預測未來價格，只是延續性代理條件。
- 同時要求原官方大盤條件與當時合法的RF BUY。缺資料、HOLD、SELL、過晚或非法預測均不得延期。
- 全部通過才延期一次，最多增加54根；總持有216根為最晚出場決策點。延期每根收盤重查，任一條件失效，安排下一根合法可交易K開盤估計出場。
- 原停損、技術轉弱、資料缺口與期末清算優先，不得被延期取消；不下調停損，不重置原持有計數。
- 延期期間凍結股數，不加碼；原到期前的加碼仍最多一次、同一段1%風險預算，不作任何放寬。
- 非當日沖銷、09:10開市限制等成交假設繼續適用，可能使實際估計成交晚於216根決策點；不能宣稱保證在第216根賣出。
- 每次延期判斷記錄時間、交易編號、各項通過條件、ML狀態、成本後浮盈、原停損、累計持有與原因。結果含 holding_events CSV、延期次數、實際出場原因。

## 加碼風險怎麼算

1%是整段持倉的估計損失預算，不是可投入金額，也不是每次買入都新給1%。
實際上限取初始鎖定預算與當下淨值1%的較小者。原部位占用估算包含買價至共同停損的價差、已付費用，以及估計出場費稅、滑價與跳空緩衝。
新增部位只能使用剩餘額度，還要付新增買賣費用，並同時符合現金和流動性限制。浮盈不自動釋放額度，停損仍停在原位時，大部分原風險仍在。沒有新增風險預算，不會因現金多而強行加碼。

母實驗聯電首次買進5922股、46.72335元，花費277088.68元，現金約722911.32元；共同停損45.55526625元。
既有部位的風險占用估計9987.94元，10000元預算剩12.06元，低於新增買賣最低費用合計40元，因此後續加碼候選股數為0。這是風險不足，不是沒有現金。
這不是實際損失保證；跳空、延後出場及近似成交均可能令損失超過預算。
