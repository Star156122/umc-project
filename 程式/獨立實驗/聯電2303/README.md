# 聯電 2303：固定規則跨股票重測

- 使用者指定：2023/01/01～2024/12/31，只測原策略＋ML、修改策略＋相同 ML。
- 本輪是既有已曝光開發資料的固定規則重測，不是 Clean Validation。沒有為聯電調參，不據結果換模型。
- 初始資金每組 100 萬、每段風險 1%、停損觸發 2.5%、原持有上限 162 根、固定 RF OOF、BUY-only、每邊 0.05% 滑價及零滑價對照，都沿用聯發科實驗。
- 普通交易 K 線近似零股數量成交，前均量代理不等於真實零股流動性。沿用整段不當沖、09:10 前不成交的保守近似；對聯電可能含整股與零股混合委託，本模型不精細拆分可即時賣出的庫存。
- 原策略保留 1,000 股封頂／40% 進場曝險上限；修改版依原先定義取消，風險與費用計算不變。低價股的股數可能差很多，因此必須一起比較曝險，不能將投入更多當作訊號改善。
- 保留原五股市場代理規則，排除目標聯電後使用其餘四股；修改版仍用官方加權指數前一日收盤高於 SMA20。
- 現金股利依聯電官方每千股表換成每股，非美國 ADS 股利；除息認列應收、發放日才可用現金。歷史支付日列來源及交叉查核。
- 僅變更目標股、相應股利資料及資料夾路徑。新模擬器是前一實驗的快照，完整來源雜湊及允許差異會在回測前保存。
- 預計五份 HTML：兩組各一份篩選過程、一份含估計買賣點的回測分析，加一份總比較。報告保留既有白話策略名稱與報酬率卡片。
- 共同合法日期為主要新舊對照，各版本全日期為補充；不把兩檔不同日期資格的績效合併平均。報告另列聯發科既有 C/D 結果作描述性跨股票觀察。
- 本次所有檔案集中此目錄；既有聯發科成果、原策略與原始資料庫保留。
