# 股票畢業專題 App

本版本功能：

- Yahoo Finance 台股熱門行情與搜尋
- MySQL/MariaDB `畢業專題` 資料庫
- 登入 / 註冊
- `favorite_stocks` 自選股
- 分析頁可選 MA / RSI / MACD 真實 Python 回測
- 可讀取第二份 SQL 中既有的 MA / RSI / MACD / Bollinger / Breakout 回測結果
- 新回測完成後存入 `analysis_records`、`backtest_results`、`technical_indicators`、`reports`

完整設定請看：`README_畢業專題資料庫與策略回測.md`
