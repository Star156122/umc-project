# 中英股票名稱與置中版面更新

## 股票名稱顯示規則

1. Yahoo Finance 有回傳中文名稱時，顯示中文。
2. 常見台股有中文名稱對照時，顯示中文。
3. 找不到中文名稱時，保留 Yahoo Finance 回傳的英文名稱。
4. 中文與英文名稱都無法取得時，才顯示 Yahoo 股票代號，例如 `9999.TW`。
5. 價格、漲跌、成交量與走勢仍由 Yahoo Finance 取得，不會自行產生行情數字。

自選股頁載入時，會把目前顯示名稱同步更新到 MySQL `stocks.stock_name`。

## 版面調整

首頁、自選股、設定頁已和分析頁統一：

- 內容最大寬度為 760。
- 網頁寬螢幕時置中顯示，不再橫向占滿整個畫面。
- 手機畫面保留左右 12px 間距。
- 頁面標題改成圓角卡片，和分析頁相同。
- 股票卡片、提示卡片與設定卡片都限制在相同內容寬度內。

## 啟動

